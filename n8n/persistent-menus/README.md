# Persistent My requests

Apply this overlay to a fresh private export containing My requests. It refreshes only `snakeMyRequestsV1` and `snakeChoiceCompactionV1`, retaining ownership checks, native claims and final confirmation safeguards.

Open My requests menus remain usable after the previous 30-minute deadline. A successful action updates legacy menus' stored lifetime. Maintenance preserves open navigation; closed and handled rows still follow normal compaction. Media and expiry confirmations keep their existing lifecycle.

The maintained public workflow bundle includes this overlay. Private exports must stay outside Git.
