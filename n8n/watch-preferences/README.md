# Watch addresses

Open My requests, select a title and choose Watch address. Local, Tailscale or Both is saved for that account on that platform. Only configured backend links are used; users cannot enter arbitrary addresses.

Settings use native pending-table rows with a distinct `settings` state. Replies and completion notifications read the newest setting for the immutable user ID. Missing or invalid settings keep the existing usable links.

Apply this overlay after My requests. It adds a small shared workflow and delivery-boundary calls; media lookup and retention policy remain unchanged.
