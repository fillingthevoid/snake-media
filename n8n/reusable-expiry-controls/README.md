# Reusable expiry controls

Original download-success and My requests detail controls remain available after Extend or Keep is selected. Each click creates a fresh, owned confirmation. Discord displays it privately; Telegram sends a separate card. Final confirmations are one-use and report saved changes after success.

The `preserveOriginalControls` response flag prevents transports from editing, consuming or linking the reusable parent with a child confirmation. Other confirmation cleanup stays unchanged.

Apply the overlay to a fresh private export, install the matching Telegram custom control node and deploy the Python bot update. The public bundle includes this overlay. Retain private rollback exports before native import/publish.
